## CSS Techniques Used

- Global `box-sizing: border-box`
- Google Font (Inter)
- Box Model
  - Padding
  - Border
  - Border Radius
  - Margin
- Typography hierarchy
- Flexbox for centering
- `:hover` pseudo-class
- `::before` pseudo-element
- Responsive card layout
