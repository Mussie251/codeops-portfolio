#Variables & Types
const by default, let when reassigning; seven
primitives, with string, number and boolean doing
most work.

#Coercion & ===
JavaScript converts types silently. Convert on
purpose with Number(); always compare with ===.

#Expressions
Arithmetic, comparison and logical operators build
values; template literals build readable strings.

#Branching
if / else and switch choose a path; the ternary is a
one-line either-or.

#Loops
for for a known count, while until a condition flips,
for...of to walk a list; break and continue steer
them.

#Scope & hoisting
let / const are block-scoped and live in a TDZ until
declared. Declare before use; default to strict
mode.
